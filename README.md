# OfferFit AI Assistant

"Build a single-page Next.js app called OfferFit with Tailwind CSS. It has a banner saying 'AI Interviewer Active (PS4)'. It lets students paste their Resume and a Job Description, has a 'Load Sample Data' button, and calls an API to return: match score, missing keywords, 2 improved STAR bullet points, and 3 likely technical interview questions. Display results in clean cards."
